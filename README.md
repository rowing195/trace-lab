# Trace Lab｜傅立葉描形實驗室

用滑鼠、觸控筆或手指畫出一條路徑，或丟入一張圖片自動描出輪廓，放開後自動計算傅立葉公式。調整 N（0–256），比較重建輪廓、雙軸旋轉圓动画與正規化均方根誤差。

## 執行

需安裝 Node.js 18 或以上，無須安裝套件。

```sh
npm start
```

開啟 http://127.0.0.1:4173 。可使用 `PORT` 環境變數調整埠號。靜態檔案皆位於 `dist/`，亦可部署至任意靜態網站主機。字型無法連線時會使用系統字型。

## 部署

推送到 `main` 時，GitHub Actions（`.github/workflows/pages.yml`）會先執行 `npm test` 與 `npm run check`，通過後才把 `dist/` 發布到 GitHub Pages：<https://rowing195.github.io/trace-lab/>。也可以在 Actions 頁面手動執行「Deploy to GitHub Pages」。

第一次使用前，需在 repo 的 Settings → Pages 把 Source 設為「GitHub Actions」。

## 操作

- 在「先畫一筆」區按住滑鼠畫一筆，新的一筆會取代舊路徑。「平滑手繪筆跡」（預設開啟）會先去除滑鼠與手指的抖動，起點與終點不動。
- 也可以從圖片開始：把圖片拖到頁面上、按 Ctrl+V／⌘V 貼上，或點「從圖片描出輪廓」選擇檔案（手機可開相簿或相機）。預設描出最大主體的外輪廓；「明暗門檻」、「反轉主體與背景」可微調，「全部線條（實驗）」會把所有輪廓接成一筆。透明背景的 PNG 會直接依透明度描邊。
- 內建八個範例：愛心、星形、花瓣三個數學曲線，以及貓咪、兔子、蝴蝶、音符、台灣五個細節較多的輪廓。
- 開啟自動連接，末點會以直線接回起點；關閉時沿原路往返形成週期，適合開放曲線。
- N 輸入框、滑桿、快速按鈕或誤差曲線皆可變更階數。
- 以播放、暫停、重新播放、進度拖曳與速度選单控制動畫。空白鍵播放／暫停，R 重播。
- 展開係數表、複製完整公式或匯出 JSON（含完整精度係數、樣本和誤差定義）。
- 「顯示設定」可展開原始路徑、旋轉圓與完整輪廓的開關；上方「公式」可直接跳到計算結果。
- 依 Taste Skill 的 Split Stage 構圖重新設計：冷藍動畫區在桌面捲動時保持可見，右側集中繪圖與 N 值；公式使用獨立淡綠色塊。X、Y 與重建路徑分別使用藍、赭紅與深藍色，動畫旁同步顯示誤差。手機提供畫布與動畫間的直接連結。
- 自動儲存最後一筆圖形、N 與選項至本機瀏覽器，不向伺服器傳送筆跡或圖片。圖片本身不會儲存，重新整理後保留的是描出的輪廓。
- 偵測系統「減少動態效果」設定時，初始動畫會暫停。

## 數學定義

原始路徑等比例正規化，外框最長邊為 2，外框中心為原點，Y 軸向上。沿路徑等弧長取 1,024 點，以免繪製速度影響擬合。

對每個軸使用實數傅立葉級數：

`x(t) = cx + Σ[k=1..N](ax[k] cos(kt) + bx[k] sin(kt))`，Y 軸類同，`t ∈ [0, 2π]`。

N 是最高諧波階數，每軸有 N 個旋轉圓與 2N + 1 個純量係數。小於 0.35 螢幕像素的圓略過外框繪製，但仍參與座標運算。N = 0 時只顯示平均位置。

`NRMSE (%) = 100 × sqrt(mean((x − x_fit)² + (y − y_fit)²)) / 原始取樣點外框對角線`

誤差使用同參數取樣點的距離，非面積誤差。利用 Parseval 等式計算各階誤差，測試另以逐點重建驗證。此計算不包含原始筆跡至重採樣折線的誤差，256 階也不保證完全重建。

### 手繪平滑

手繪筆跡先依弧長等距重取樣，再以高斯核平滑，σ 為外框最長邊的 2.5%（`smoothPath`，強度 0.05 × 半邊長）。視窗在兩端對稱縮小，因此起點與終點保持原位；結果與繪製尺寸無關。範例與圖片不做平滑。

### 圖片描邊

`dist/edge.js` 不依賴任何套件，全部在瀏覽器內執行：

1. 圖片縮小到最長邊 480 px，合成在白底上取亮度；外框多為透明時改用透明度。
2. 高斯模糊（σ = 1.2 px）後以 Otsu 法求門檻；依外框亮度判斷主體較暗或較亮，可手動反轉。
3. 以 marching squares 在模糊後的亮度場上求等值線，取得次像素、自然平滑的封閉輪廓。
4. 「外輪廓」取面積最大的輪廓；「全部線條」把周長達最長輪廓 2% 的輪廓（最多 60 條）以最近鄰順序接成一筆，輪廓之間會有直線。
5. 以 Douglas–Peucker（0.3 px）簡化後，交給與手繪相同的傅立葉流程。

主體與背景對比高（剪影、圖示、Logo、單純背景的照片）時效果最好；背景雜亂的照片需要調整門檻，不保證能分出主體。

### 內建輪廓

`dist/shapes.js` 由 `npm run shapes`（`tools/build-shapes.mjs`）產生：貓咪、兔子、蝴蝶、音符為以有號距離場組合的原創剪影，用與圖片相同的 marching squares 描邊；台灣本島輪廓取自 Natural Earth 1:10m Admin 0 Countries（公有領域），簡化至約 400 m。

## 驗證

```sh
npm test
npm run check
```

測試涵蓋圓形的單諧波重建、等弧長取樣、Parseval 與直接 RMSE 一致性、誤差單調性、開放及退化路徑、匯出公式數值；以及 Otsu 門檻、marching squares 次像素精度、Douglas–Peucker、深色／淺色／透明背景主體、外輪廓與全部線條模式、空白圖片、手繪平滑（端點不動、與尺寸無關）和每個內建輪廓的重建誤差。

UI 設計來源、對工具介面的調整與驗證記錄見 [DESIGN.md](./DESIGN.md)。
